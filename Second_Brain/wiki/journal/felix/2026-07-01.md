### Key operational discovery (team-relevant)

- OpenCode loads oh-my-openagent from its OWN sandbox at `~/.cache/opencode/packages/oh-my-openagent@latest/node_modules/oh-my-openagent/dist/`, NOT from `file://` specs or config `node_modules` junctions.
- To test a local build: `bun build` the entry, then `bun run build:shared-skills-assets` (index.js reads `dist/skills/*/SKILL.md` at import time), then copy the full `dist/` (index.js + cli + skills) into the sandbox. Missing skills => silent load failure (no log, falls back to "build" agent).

## Fetch-path pagination support

- Added `detectPaginationNextFromHtml` so pagination auto-follow now works in fetch-only mode, not just the Playwright path. Previously `scrapeWithFetch` always returned `paginationNext: null`.
- Mirrors the browser detector's three strategies on a raw HTML string: `<link rel="next">` / `<a rel="next">`, a next-labeled anchor scoped to pagination containers, and `?page`/`?p` + 1 inference on the same origin.
- Design principle: read the site's declared next href rather than string-guessing the URL, so dynamic schemes keep working; the numeric fallback is last-resort only.
- Volume left intentionally shallow per request — still bounded by `domainPageCap=5` / `maxPages=10` (cap 15), no deep (>10 page) traversal.
- Verified: 7 new given/when/then tests pass; `typecheck:packages` EXIT=0.

## Normalization layer for local web-search output

- The two local code paths had diverged: the direct `web_search` tool emitted `### [N] Title / **URL:** / content` markdown (uncapped), while the `websearch-local-redirect` hook emitted Exa-style `Title:/URL:` text capped at 1500 chars. Same `CrawlResult`, two LLM-facing shapes.
- Introduced `format-results.ts` with a single `formatWebSearchResult(result)` renderer; both the direct tool and the redirect hook now render through it, so entry point no longer changes the response shape.
- Standardized the per-entry content cap to `MAX_RESULT_CONTENT_CHARS = 2000`; the empty case is also routed through the formatter in both paths.
- Scope note: only the LOCAL crawler output is normalized. Remote Exa/Tavily MCP output stays owned by the remote server and is consumed by the LLM as free text — deliberately out of scope.
- Verified: `bun test packages/omo-opencode/src/tools/web-search-local/` → 10 pass / 0 fail; `typecheck:packages` EXIT=0.
